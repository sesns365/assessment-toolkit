# 鑑定評估小工具箱

[開啟網站](https://atk.se365edu.com)

四項評估工具、三份可填寫訪談表，以及空白表單與參考文件下載。

填寫與計分內容只在使用者瀏覽器內處理及暫存，不上傳至 GitHub 或雲端資料庫。以 JSON 備份保存草稿，或依原範本版式匯出已填 PDF 與 Word。

情緒行為障礙與自閉症學生訪談表，可逐題新增或移除「相關人員」欄位，並隨草稿保存及匯出。

網站採用靜態 HTML、CSS 與 JavaScript，透過 GitHub Pages 發布；main 分支根目錄即為公開網站。儲存庫只含工具程式與空白資源。

來源問項與原工具的著作權歸原作者；詳見工具或表件中的來源標示。
