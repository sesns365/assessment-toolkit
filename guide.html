訪談紀錄的填寫流程

  1. 在首頁選擇訪談表，建立一份本機草稿，依原表問項填寫。
  2. 編輯時查看暫存狀態。回到同一網站、同一瀏覽器，可接續這台裝置的草稿。
  3. 需要改日繼續或換電腦時，下載 JSON 備份。之後從相同表單匯入，建立可繼續編輯的草稿。
  4. 完成後下載已填 PDF 或 Word；輸出依空白原範本的欄位與版式填入。需要列印時，開啟下載的 PDF 列印即可。空白原表可從「參考下載」取得。
  5. 共用電腦使用完畢，先確認檔案已下載，再刪除個別草稿。計分工具的暫存需要在各工具內分別清除。

公開網站與本機資料

網站公開提供工具程式與空白表單。訪談輸入、草稿與計分資料由瀏覽器在本機處理，本網站不設資料上傳、帳號同步或雲端資料庫。

「本機暫存」只適用同一個網站網址、同一台裝置、同一個瀏覽器及使用者設定檔。其他人在同一個瀏覽器設定檔中可能看到草稿。使用無痕模式、清除網站資料、重設瀏覽器或儲存空間不足，都可能使暫存無法保留。

暫存不是備份。請將備份與匯出檔存放在自己管理的本機資料夾；如果下載位置設在 OneDrive 或 Google 雲端硬碟同步資料夾，該軟體仍可能依你的設定同步檔案。

載入網站會下載工具程式與空白資源。使用者填寫內容不會隨之上傳；離線工具中的語音僅使用裝置提供的本機語音。若裝置沒有可用的本機語音，需先在作業系統安裝語音，才能報讀。

暫存、備份與匯出的差別

方式用途保存位置
本機暫存關閉後接續編輯目前瀏覽器
JSON 備份還原或轉移可編輯草稿你選擇的下載資料夾
Word 匯出保留原表版式，可繼續編修你選擇的下載資料夾
PDF 匯出依原表版式輸出，開啟後即可列印你選擇的下載資料夾
文字匯出保留純文字紀錄你選擇的下載資料夾

「JSON 備份」可重新匯入網站；修改過的 Word、PDF 或文字檔不會自動回寫網站草稿。下載檔案可能含有敏感資料，請依學校既有方式保管。
